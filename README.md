# موکاپ‌ساز ویدیویی تی‌شرت

این پروژه شامل دو فایل است:
- **`mockup.py`**: موتور اصلی پردازش (منطق ردیابی بدن، چسباندن طرح، ادغام صدا). قابل استفاده از خط فرمان.
- **`app_py.py`**: یک رابط کاربری وب با Streamlit که همان موتور را با آپلود فایل صدا می‌زند.

هر دو فایل باید کنار هم در یک پوشه/ریپازیتوری باشند چون `app_py.py` تابع `process_video` را از `mockup.py` ایمپورت می‌کند.

## نصب (اجرای محلی)

```bash
pip install -r requirements.txt --break-system-packages
```

همچنین `ffmpeg` باید روی سیستم نصب باشد (برای حفظ صدای ویدیوی اصلی):
- ویندوز/مک/لینوکس دسکتاپ: از سایت رسمی ffmpeg یا با `brew install ffmpeg` / `apt install ffmpeg`
- اندروید (Termux): `pkg install ffmpeg`

> نکته: اولین باری که برنامه را اجرا کنید، به‌طور خودکار یک فایل مدل تشخیص بدن
> (حدود چند مگابایت) از سرورهای گوگل دانلود می‌کند. برای این کار به اینترنت نیاز دارید،
> فقط برای همان یک بار.

## اجرا به‌صورت وب (Streamlit) — روش پیشنهادی برای موبایل و دسکتاپ

```bash
streamlit run app_py.py
```

یک صفحه‌ی وب باز می‌شه که می‌تونید ویدیو و طرح PNG رو آپلود کنید، پارامترها رو با اسلایدر تنظیم کنید،
و در پایان ویدیوی خروجی رو پیش‌نمایش و دانلود کنید.

### دیپلوی روی Streamlit Cloud
1. هر ۶ فایل (`mockup.py`, `app_py.py`, `requirements.txt`, `packages.txt`, `runtime.txt`, `README.md`) رو تو یک ریپازیتوری گیت‌هاب بذارید.
2. تو تنظیمات اپ streamlit، **Main file path** رو روی `app_py.py` بذارید (نه mockup.py).
3. Deploy/Reboot کنید.

## اجرا به‌صورت خط فرمان (CLI)

```bash
python3 mockup.py --video input.mp4 --design design.png --output output.mp4
```

## پارامترهای تنظیمی

| پارامتر | توضیح | پیش‌فرض |
|---|---|---|
| `--width-scale` | عرض طرح نسبت به فاصله دو شانه | 0.62 |
| `--height-scale` | نسبت ارتفاع به عرض طرح | نسبت طبیعی خود PNG |
| `--vert-offset` | فاصله از خط شانه تا بالای طرح | 0.35 |
| `--blend` | شدت افکت چروک/سایه پارچه روی طرح (0 تا 1) | 0.35 |
| `--smoothing` | صاف‌سازی حرکت بین فریم‌ها (0 تا 0.95) | 0.6 |
| `--model` | `lite` (سریع‌تر) یا `full` (دقیق‌تر) | lite |

اگر طرح خیلی بزرگ/کوچک یا بالا/پایین قرار گرفت، این چند پارامتر بالا را با آزمون‌وخطا تنظیم کنید.

## روی موبایل هم اجرا می‌شود؟

بله، از طریق:
- **اندروید**: با Termux (`pkg install python ffmpeg` سپس `pip install ...`) یا Pydroid 3
- **آیفون**: محدودتر است؛ Pythonista یا a-Shell را امتحان کنید، ولی نصب mediapipe روی iOS معمولاً پشتیبانی نمی‌شود — بهتر است پردازش را روی دسکتاپ انجام دهید و فقط فیلم‌برداری را با موبایل بگیرید.

برای فیلم‌های طولانی یا موبایل‌های ضعیف، پردازش ممکن است چند دقیقه طول بکشد چون هر فریم جداگانه تحلیل می‌شود.

## محدودیت‌های این روش (صادقانه بگویم)

- اگر فرد خیلی سریع بچرخد یا پارچه شدیداً تا بخورد، طرح ممکن است کمی "شناور" به‌نظر برسد؛ پارامتر `--smoothing` را بالاتر ببرید.
- نور و سایه‌ی واقعی پارچه فقط با یک تقریب ساده (ترکیب با نسخه خاکستری فریم) شبیه‌سازی می‌شود، نه یک مدل نوردهی واقعی سه‌بعدی.
- اگر تی‌شرت خیلی شل/گشاد باشد یا فرد پشت به دوربین کند، تشخیص شانه ممکن است ناپایدار شود.

برای کیفیت حرفه‌ای در حد ابزارهای تجاری (Placeit و مشابه)، معمولاً از مدل‌های تشخیص پارچه و
displacement map اختصاصی استفاده می‌شود که ساخت آن از صفر پروژه‌ی مجزا و بزرگ‌تری است.
